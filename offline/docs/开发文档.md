## 1. 随机森林推荐模块（`recommend_random_forest.py`）

- **用途**：根据问卷与用户–景点行为特征，用 `RandomForestClassifier` 预测「喜欢/不喜欢」；与 `recommend_sights.recommend_by_mixture` 做 Borda 融合（权重 `WEIGHT_RANDOM_FOREST` / `WEIGHT_HYBRID_CF`）。
- **特征**：点赞、收藏、评论数、预订、推荐反馈、问卷（景点类型/出行/旅行方式/预算）、景点侧统计（收藏/点赞/浏览/评分人数、均分）。
- **标签**：评分 ≥6 为 1，否则 0。
- **模型文件**：项目根目录 `randomforest.joblib`（路径相对本模块文件，不依赖进程工作目录）。
- **训练**：`run_train()`；样本过少时跳过训练。
- **冷启动**：无模型、无问卷或预测为空时退化为热门景点。

## 2. 协同过滤模块（`recommend_sights.py`）

### 2.1 基于用户的协同过滤（UCF）直观说明

通过比较用户对相同物品的评分（或共现）计算用户相似度；对当前用户未评分的物品，用相似用户的高分物品推荐。

示例（用户–物品评分矩阵）：

|     | X   | Y   | Z   | R   |
|-----|-----|-----|-----|-----|
| a   | 5   | 4   | 1   | 5   |
| b   | 4   | 3   | 1   | ?   |
| c   | 2   | 2   | 5   | 1   |

a 与 b 兴趣相近，b 未评 R，可将 a 对 R 的高分作为推荐依据。

### 2.2 基于物品的协同过滤（ICF）

构建物品共现与相似度矩阵，按用户历史评分与物品相似度加权得到候选排序。混合推荐按用户对推荐反馈动态分配 UCF / ICF 列表比例。

数学公式与业务叙述见 **`算法说明.md`**。

## 3. 用户端提示语与排错（前台）

| 场景 | 用户可见（简短） | 维护者排查 |
|------|------------------|------------|
| 身份证识别 | 请求方法错误 | 仅接受 POST |
|  | 请上传身份证图片 | 检查表单字段 `id_card_image` |
|  | 请上传图片文件（jpg、png、bmp） | 扩展名校验 |
|  | 图片大小不能超过 20MB | 调整大小或服务器限制 |
|  | 图片无法读取 | 文件损坏或非真实图片 |
|  | 图片尺寸过小 | 建议 ≥ 约 200×300 像素 |
|  | 未能识别，请换一张更清晰… | 换清晰正放、光线均匀、号码区完整 |
|  | 无法自动识别身份证，请手动填写… | 未安装或未检测到 Tesseract，见 §4 与 TESSERACT安装.md |
|  | 处理失败，请稍后重试 | 查看服务端日志（不向用户暴露异常详情） |
| 人脸登录/注册 | 获取人脸失败… | 摄像头权限、未检测到人脸 |
| 推荐反馈 | 参数有误 / success | 检查 POST 参数 |
| 酒店导入等 JSON | 成功/失败简短文案 | 见对应视图逻辑 |

**原则**：异常分支不向用户返回 `str(e)` 等技术细节，仅打日志。

## 4. 身份证识别与 Tesseract（管理员）

- **用户短提示**：当 `TESSERACT_AVAILABLE` 为假时，前台提示「文字识别未配置」类短句，完整安装步骤见 **`TESSERACT安装.md`**。
- **识别失败（已安装）**：换图、提高分辨率、避免反光与模糊；算法细节见 `travel/id_card_recognition.py`（OpenCV 预处理 + Tesseract + 校验位）。

## 5. 后台爬虫与依赖（xadmin「一键爬取」）

- **成功**：任务后台运行，结果追加到项目根目录 `travel.txt`，再通过「导入数据」入库。
- **缺少依赖**：执行  
  `pip install beautifulsoup4 requests fake-useragent`  
  镜像与验证见 **`爬虫依赖安装.md`**（项目中无 `install_spider_deps.bat` 时以 pip 为准）。
- **爬虫代码位置**：`travel/spiders/travel_spider_data.py`；城市去重列表 `offline/data/citys.txt`。

## 6. 表单与校验

- **手机号**：`travel/forms.py` 使用正则 `^1[3-9]\d{9}$`（11 位大陆号），注册与个人资料一致。
- **密码等**：见 `RegisterForm` / `Edit` 中 `clean_*` 方法。
