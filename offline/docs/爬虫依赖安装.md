# 爬虫依赖安装说明

## 问题

运行「一键爬取旅游信息」等功能时出现：

```
ModuleNotFoundError: No module named 'bs4'
```

## 解决方式

### 1. 直接安装（推荐）

在项目所用 Python 环境中执行：

```bash
pip install beautifulsoup4 requests fake-useragent
```

### 2. 使用国内镜像（网络较慢时）

```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple beautifulsoup4 requests fake-useragent
```

### 3. 与项目依赖一致

```bash
pip install -r requirements.txt
```

## 涉及模块

| 包 | 用途 |
|----|------|
| beautifulsoup4 | HTML 解析 |
| requests | HTTP 请求 |
| fake-useragent | 随机 User-Agent |

## 验证

```bash
python -c "import bs4; import requests; import fake_useragent; print('OK')"
```

## 注意

- 使用与运行 Django **同一** Python/虚拟环境。
- 使用 venv 时先 `activate` 再 `pip install`。
